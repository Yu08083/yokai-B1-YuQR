QRを読み取る前に、次の状態にしてください（赤猫団内の月兎組 v2.3）。

  1. かべがみを「ふんわりバスターズ」に設定する。
  2. 1Fエントランスに「うんがい三面鏡」と「ウィスパー」を出現させる。
  3. リフォームの内装・外装をどちらも「おんぼろアパート」にする。
  4. チーム編成を上から順に ふぶきちゃん、うんがい三面鏡、ワカメくん、コンブさん にする（操作キャラはふぶきちゃん）。
  5. QR読み取りNPC（コンブさん）の前でセーブする。
  6. 端末を再起動してセーブをロードし、他に何もせずすぐQRを読み取る。

読み取り後は「無効なQRコードを使用しています。」と出ますが、そのまま閉じれば反映されています。

QRはOld 3DSとNew 3DSで別です。 右上の「機種」を、実際に遊ぶ本体に合わせてください。間違えると読み取り後に落ちます。

鉄鬼軍ルートで読み取る場合の状態です（赤猫団内の月兎組 v2.3）。

  1. 操作キャラを「まむし行事」にする。
  2. それ以外の準備（チーム編成・うんがい三面鏡など）は外す。
  3. かべがみ・おんぼろアパートは通常ルートと同じにする。
  4. 鉄鬼軍の連動用機会の前でセーブする。
  5. 端末を再起動してセーブをロードし、他に何もせずすぐQRを読み取る。

読み取り後は「無効なQRコードを使用しています。」と出ますが、そのまま閉じれば反映されています。

QRはOld 3DSとNew 3DSで別です。 右上の「機種」を、実際に遊ぶ本体に合わせてください。

できない人用 QRを読み込んでも反映されないとき

次の順で確認してから、もう一度はじめから行ってください。

  1. 機種の切り替えが合っているか（旧3DS / New 3DS）。
  2. チーム編成と操作キャラが手順どおりか。
  3. セーブ → 再起動 → ロード後に、他に何もせずすぐ読み取っているか。
  4. QRが読み取りにくいときは、QR表示の「読み込みやすくする」を使う。
