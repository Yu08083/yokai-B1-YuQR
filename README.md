# 妖怪ウォッチバスターズ 赤猫団 v2.3（月兎組） QRまとめ

妖怪ウォッチバスターズ 赤猫団 Ver.2.3（月兎組）で、QRコードから
アイテム・妖怪・ボス図鑑・レジェンド・トロフィー・フラグを追加するための
QR画像をまとめた静的サイトです。

- アイテム 1,507件（上限99のものは99個）
- 妖怪 428件（通常図鑑）
- ボス図鑑 42件
- レジェンド 8件（封印解除）
- トロフィー 84件＋まとめて解除14件
- フラグ 213件（イベント・ミッション）

## 使い方

1. 右上の「機種」で **旧3DS / New 3DS** を選ぶ（セーブの本体に合わせる）
2. タブ（妖怪 / アイテム / ボス図鑑 / レジェンド / トロフィー / フラグ）を選ぶ
3. 名前で絞り込み、行をクリックしてQRを表示
4. QRを3DSのカメラで読み取る

旧3DSとNew 3DSではQRの配置が違います。機種を間違えると正しく反映されません。

読み取りにくいときは、QR表示の **「読み込みやすくする」** を押すと
白画面にQRだけを大きく出します。クリック / Esc で戻ります。
このときQRは1モジュール=整数pxで描き直すので、拡大しても輪郭が崩れません。

レジェンド（v26）やトロフィーのまとめて解除（v24）はモジュール数が多いので、
画面が小さいと読み取りにくいです。PCの画面で開くか、画像を保存して印刷してください。

## 前提

- 赤猫団内の月兎組 v2.3
- かべがみ「ふんわりバスターズ」
- 1Fエントランスに うんがい三面鏡 と ウィスパー
- リフォームは内装・外装とも「おんぼろアパート」
- チーム編成は ふぶきちゃん / うんがい三面鏡 / ワカメくん / コンブさん（操作はふぶきちゃん）
- QR読み取りNPC（コンブさん）の前でセーブ → 再起動 → ロード後すぐ読み取る

## 構成

```
index.html        画面
app.js            一覧・検索・QR表示・読み込みやすくするモード
catalog.js        収録データ（window.qrCatalog）
style.css
qr/old3ds/item/      アイテムQR（旧3DS）
qr/old3ds/yokai/     妖怪QR（旧3DS）
qr/old3ds/boss_dex/  ボス図鑑QR（旧3DS）
qr/old3ds/legend/    レジェンド封印解除QR（旧3DS）
qr/old3ds/trophy/    トロフィーQR（旧3DS）
qr/old3ds/flags/     フラグQR（旧3DS）
qr/new3ds/…          同じ構成（New 3DS）
```

画像はすべて可逆WebP（`VP8L` のみ、メタ情報なし）です。

## 生成

QRは `ywb_export.py` で作り、`busters/site/build.py` が `catalog.js` と `qr/` を組み立てます。

```
python ywb_import.py                     # Busters.md → busters_catalog.json
python ywb_export.py --out busters/qr    # 旧3DS / New 3DS 両方
python busters/site/build.py             # → dist/catalog.js, dist/qr/*
```
