# 妖怪ウォッチバスターズ 赤猫団 v2.3（月兎組） QRまとめ

QRコードから、妖怪・アイテム・ボス図鑑・トロフィー・フラグを追加するための画像集です。
画像はすべて可逆WebP（1280×1280、メタ情報なし）です。

## 使い方

1. 右上の「機種」で **旧3DS / New 3DS** を選ぶ（セーブの本体に合わせる）
2. タブ（妖怪 / アイテム / ボス図鑑 / トロフィー / フラグ）を選ぶ
3. 名前で絞り込み、行をクリックしてQRを表示
4. 3DSのカメラで読み取る

機種を間違えると正しく反映されません。

## 前提

- 赤猫団内の月兎組 v2.3
- かべがみ「ふんわりバスターズ」
- 1Fエントランスに うんがい三面鏡 と ウィスパー
- リフォームは内装・外装とも「おんぼろアパート」
- チーム編成は ふぶきちゃん / うんがい三面鏡 / ワカメくん / コンブさん（操作はふぶきちゃん）
- QR読み取りNPC（コンブさん）の前でセーブ → 再起動 → ロード後すぐ読み取る

## 構成

```
index.html / app.js / style.css / catalog.js
qr/old3ds/{item,yokai,boss_dex,flags,trophy}/
qr/new3ds/{item,yokai,boss_dex,flags,trophy}/
```
